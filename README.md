# 프론트엔드 파트 역할 분담

### 개발 환경
- Android Studio(애뮬레이터), React Native(TypeScript), Git/GitHub 환경 구축

### 화면 구현
- 홈 화면 - 전체 북마크 조회 @홍예령
- 폴더 화면 - 폴더 목록 조회, 생성, 수정, 삭제 @공동개발
- 북마크 목록 화면 - 북마크 조회, 삭제, 이동, 즐겨찾기 @공동개발
- 검색 화면 - 북마크 검색 @홍예령
- 추천 화면 - 오늘의 갈피, 최근 저장 북마크 @공동개발
- 회원가입 / 로그인 화면 @강다원
- 설정 화면(마이페이지) @강다원

### API 연동
- 북마크 API 연결 @홍예령
- 폴더, 회원 REST API 연결 @강다원

### 기타
- Android Intent+ Kotlin 을 통한 다른 앱에서 공유된 링크 자동 저장 @공동개발
