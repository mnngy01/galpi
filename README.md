# 프론트엔드 파트 역할 분담 (공동개발)

### 개발 환경
- Node.js, Android Studio, React Native, Git/GitHub 환경 구축

### 화면 구현
- 홈 화면 - 전체 북마크 조회
- 폴더 화면 - 폴더 목록 조회, 생성, 수정, 삭제
- 북마크 목록 화면 - 북마크 조회, 삭제, 이동, 즐겨찾기
- 검색 화면 - 북마크 검색
- 추천 화면 - 오늘의 갈피, 최근 저장 북마크
- 로그인 / 설정 화면

### API 연동
- 북마크, 폴더, 회원 REST API 연결

### 기타
- Android 외부 공유 기능 구현 (다른 앱에서 갈피로 링크 공유)
